\# FC ARENA



FC ARENA is a football/esports tournament and community management platform.



\## Features



\- Authentication and OTP

\- Player profiles and FC ARENA IDs

\- League creation and join requests

\- Tournament creation

\- SOLO / DUO / TEAM modes

\- Round Robin and Knockout

\- Fixture generation

\- Match scheduling

\- Match Center

\- Manual result entry

\- Screenshot OCR result processing

\- Result verification

\- Statistics and standings

\- Rankings

\- Achievements

\- Notifications

\- Player career history

\- RBAC and audit logs

\- Responsive mobile and desktop UI



\## Tech Stack



Frontend:

\- Next.js

\- React

\- TypeScript

\- Tailwind CSS



Backend:

\- NestJS

\- Prisma

\- PostgreSQL



Infrastructure:

\- Redis

\- BullMQ

\- Docker



OCR:

\- Tesseract.js

\- Sharp



Testing:

\- Supertest
